## Appendix A
### Prompt Templates for the Five Major Modules.
There are five modules: feature engineering, hyperparameter optimization, model evaluation strategies, cross-validation analysis, and algorithm characteristics analysis. 
These five modules correspond to the implementation steps of machine learning algo-rithm experiments , has its own specific prompt implementation.

## Appendix B
### Specific prompt settings for the algorithmic agents.
The five algorithmic agents, Decision Trees, Random Forests, KNN, Naive Bayes, and SVM, each have their own specific prompts. These prompts not only anchor the agent’s expert role but also translate the core mechanisms of each algorithm, such as the distance metric principle in KNN, the ensemble voting mechanism in Random Forests, and the conditional independence assumption in Naive Bayes, into semantic constraints that the LLM must strictly adhere to. 
Through this explicit injection of logic, the system effectively suppresses the divergent behavior and hallucinations of genera-tive models.
